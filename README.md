##Count Separation
A C program to split multi-digit integers into separate single digits
## Development Environment
Visual Studio 2022 | C Language
## Instructions
Clone this repository to your local machine
Open blank1.sln with Visual Studio 2022
Build and run the project to launch the program
## Project Features
Split any positive multi-digit integer into individual digits.
Example: Input number 12345 → Output separated digits: 1 2 3 4 5
